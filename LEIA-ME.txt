NOVA PRIME 3D — VERSÃO IPHONE (PWA)

Conteúdo: index.html, logo.png, manifest.webmanifest, sw.js e icons/.

COMO PUBLICAR NO GITHUB PAGES (GRÁTIS)
1. No GitHub, crie um repositório, por exemplo nova-prime-3d-iphone.
2. Envie TODO o conteúdo desta pasta para a RAIZ do repositório (não apenas index.html).
3. No repositório, abra Settings > Pages > Build and deployment.
4. Selecione Deploy from a branch, branch main, pasta / (root), e salve.
5. Aguarde a publicação; o GitHub mostrará o endereço HTTPS (ex.: https://SEU-USUARIO.github.io/nova-prime-3d-iphone/).
6. Abra o endereço no SAFARI do iPhone. Use Compartilhar > Adicionar à Tela de Início > Adicionar.
7. Abra o ícone instalado e configure seus valores fixos uma única vez.

OBSERVAÇÕES IMPORTANTES
• Não é necessário usar Android Studio, Xcode ou App Store para esta opção.
• É necessária internet para a primeira abertura e instalação; após carregar e armazenar os arquivos, a calculadora funciona offline.
• Dados e projetos ficam no armazenamento local de CADA iPhone (sem sincronização).
• O PDF é gerado pelo botão do app e salvo via menu de impressão/compartilhamento do iOS.
• Sem backup: apagar dados de sites, excluir o app ou redefinir o aparelho pode apagar os projetos e valores.
• O GitHub Pages é uma HOSPEDAGEM PÚBLICA: o código fica acessível, mas os dados inseridos pelos familiares não são enviados ao GitHub.
• Não use o endereço file:// para instalar: PWA e modo offline requerem HTTPS.
